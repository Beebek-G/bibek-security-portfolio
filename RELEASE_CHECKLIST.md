# Pre-publication checklist

- [ ] Rotate or revoke the Tailscale authorization key visible in one source screenshot and confirm it is no longer usable.
- [ ] Verify current school enrollment and intended degree title.
- [ ] Confirm public email and check updated resume contact details.
- [ ] Review cropped screenshots to confirm absence of real employee/student names, account IDs, private IPs considered sensitive, and authentication tokens.
- [ ] Link published project repositories only after source, data files, and commit history have been scrubbed.
- [ ] Obtain permission before displaying any third-party records or data.
- [ ] Install dependencies and run TypeScript / production build checks.
- [ ] Add server-side rate limiting and CSRF / bot mitigation for contact endpoint.
- [ ] Add deployment CSP and security headers, verify hosting env secrets, and test endpoint failures.
- [ ] Test responsive keyboard navigation, mobile display, reduced-motion mode and accessibility.
- [ ] Deploy and smoke-test every project page and PDF link.
